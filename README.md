This project utilizes a clear parent-child component architecture to build a dynamic and reusable user interface. 

The main `App.jsx` file serves as the parent container, holding the array of employee data and using the `.map()` method to dynamically render the layout.

 Each individual profile is generated by the reusable `ProfileCard.jsx` child component, which receives unique data (such as names, ages, and image URLs) via React Props. Additionally, each profile card manages its own independent React State to power an interactive "Follow" button.
